# Sound effects

Use a sound-effect generator (for example ElevenLabs Sound Effects): paste the description and set the length.
Save as `assets/audio/sfx/<file>.ogg`, then map it in `presentation/sound.gd` (`SOUNDS`).
The interface clicks (Kenney, CC0) are already in the game and stay.
