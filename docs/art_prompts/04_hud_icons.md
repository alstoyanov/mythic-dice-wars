# HUD icons

Small icons for the war screen, all in one shared style.

- **One conversation for all of them**, in order.
- Generate at **1024 × 1024**; the game uses them at 32–64 px.
- Save as `assets/ui/icons/<file>`.

Colour-blind player emblems need no new art: the game uses each pantheon's dice face 1.

### `favour.png`

```
A single game interface icon: a glowing golden flame in a bronze offering bowl. A bold, simple silhouette that is still readable at 32 pixels, hand-painted in a gold-and-ivory palette with a dark outline and a slight bevel, lit from the top left. Centred on a plain pure white background with a margin. No text, no letters, no numbers, no signature, no border, no frame.
```
